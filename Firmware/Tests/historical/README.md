# Superseded STM32 staging tools

These original scripts document the pre-ZIT6, independent verifier workflow.
They are retained as engineering evidence, not active migration/build tools.
Their relative roots, GP APIs, II-package paths and source-copy assumptions
refer to that historical tree and must not be used on the current firmware.

Use ../build_stm32.py and ../check_firmware_integration.py from the repository
instead. See ../../README.md for the authoritative build and safety status.
Historical records under Firmware/STAGE*.md describe their original milestones.
